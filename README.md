# 吹雪 · 学习与科研

这是吹雪的个人学术主页，使用 React + Vite 构建，记录广东技术师范大学电气工程及其自动化本科阶段的学习、科研与阶段性成果。

公开页面：<https://fubuki007.github.io/>

## 本地运行

```bash
npm install
npm run dev
```

构建并发布到仓库根目录：

```bash
npm run build
```

预览检查：

```bash
npm run preview
$env:PREVIEW_URL='http://127.0.0.1:4173/'
npm run test:preview
```

页面内容以个人简历中已填写的信息为准。课程、专业排名、初试成绩等仍为空的模板字段不会展示在页面中。
